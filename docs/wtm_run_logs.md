## wtm run logs

Attach to a job's output

### Synopsis

Without arguments, stream all running jobs (multiplexed).
With a job name, attach to that single job's PTY.
Press Ctrl+C to detach.

```
wtm run logs [job] [flags]
```

### Options

```
  -h, --help   help for logs
```
