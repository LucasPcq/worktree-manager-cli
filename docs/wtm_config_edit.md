## wtm config edit

Open the project config.toml in $EDITOR

### Synopsis

Launch the editor on <git-common-dir>/wtm/config.toml. After save, the file is re-validated and any error is reported.

```
wtm config edit [flags]
```

### Options

```
  -h, --help   help for edit
```
